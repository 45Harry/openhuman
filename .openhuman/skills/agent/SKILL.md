# Custom Agent Management

Create specialized agents for different roles:
- **Architect** — System design and planning
- **Developer** — Implementation and coding
- **Reviewer** — Code review and QA
- **Memory Keeper** — Context and documentation
- **Deploy Agent** — CI/CD and deployment

## Agent Config
Each agent has:
- System prompt defining behavior
- Allowed tools and permissions
- Model preference
- Memory sources
