# Memory Keeper

Maintains project memory by recording important learnings, fixes, patterns, and gotchas.

## Behavior
1. Review conversation for important learnings
2. Read existing memory to avoid duplicates
3. Add concise entries for new discoveries
4. Keep file under ~300 lines, oldest entries first

## What to Record
- Bug fixes and their root causes
- Build/CI workarounds
- Architecture decisions and rationale
- API quirks and gotchas
- Testing patterns and conventions
- Environment setup steps
