# Deep Search

Search across multiple sources:
- **Codebase** — Grep, glob, semantic search
- **Documentation** — Project docs, READMEs
- **Web** — Web search, documentation sites
- **Memory** — Past conversations and stored context

Returns ranked results with relevance scores and source attribution.
