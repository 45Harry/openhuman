# Voice Dictation

Configure voice input:
- Toggle push-to-talk hotkey
- Switch between tap/push activation mode
- Adjust voice server settings
- Set wake word

## Commands
- `openhuman voice` — Start voice dictation server
- `openhuman config update_voice_server_settings` — Configure voice
