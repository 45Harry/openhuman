# Configuration Management

Update any OpenHuman configuration setting:
- Model and inference settings
- Autonomy and security levels
- Integrations and channels
- Privacy mode
- Local AI settings
- Voice and dictation
- Browser automation
- Memory and learning

Use: `openhuman config <function>` with JSON via stdin.
