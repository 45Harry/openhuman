# Memory

Save important context to persistent memory. This helps the AI remember:
- Project architecture decisions
- Build and setup instructions
- Coding conventions and patterns
- API keys, endpoints, configuration
- Environment setup details

## Usage
Describe what you want to remember and the AI will store it in `~/.openhuman/<project>/memory/` for future sessions.
